# Planes

- `active/`: planes en ejecución o aprobados cuya implementación aún no termina.
- `completed/`: planes implementados y validados; se conservan como referencia.
- `future/`: ideas o evoluciones todavía no priorizadas.

Un plan se mueve de carpeta cuando cambia su estado. El estado global y los
pendientes accionables se mantienen en `../context/tasks.md`.
